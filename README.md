# Vibe Coding

## TestSphere Cards

The TestSphere cards used in this project are from the [Ministry of Testing](https://www.ministryoftesting.com/insights/testsphere-digital) and are only available to Pro members. Therefore, they are not included in this repository.

To use this project:
1. Download the TestSphere cards from Ministry of Testing (Pro membership required)
2. Place the downloaded cards into the `TestSphere Cards/` directory

## Project Structure

- `game/` - Main game implementation
- `TestSphere Cards/` - Place your downloaded TestSphere cards here

## Quick Start

1. Download or clone this repository.
2. Download the TestSphere cards (see above) and put them in the `TestSphere Cards/` folder.
3. Open `game/index.html` or `index.html` in your web browser (Chrome, Firefox, Edge, or Safari recommended).

No installation or coding required.
